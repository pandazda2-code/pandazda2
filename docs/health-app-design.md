# ふたりの健康ログ — アプリ設計書（v0.1）

夫婦2人で使う「食事・体重・睡眠・運動」の記録アプリ。食事は写真を撮るだけで Claude がメニューとカロリー・栄養素を推定して記入する。

---

## 1. 方式（どこで動かすか）

| 案 | 仕組み | 良い点 | 気になる点 |
|---|---|---|---|
| **A. claude.ai アーティファクト（推奨）** | claude.ai 上に公開する1枚のWebアプリ。写真解析はページから Claude を直接呼ぶ。データは アーティファクト内蔵DBに保存 | APIキー・サーバー・月額費用が不要／スマホのブラウザや Claude アプリで開ける／夫婦で同じURLを共有できる | 奥様にも claude.ai アカウントが必要（URLを共有して招待）。写真解析は使う人それぞれの Claude 利用枠を使う |
| B. 独自Webアプリ（PWA） | Vercel 等でホスト＋Supabase（DB）＋Claude API | ホーム画面に置ける普通のアプリ。アカウント不要にもできる | APIキー管理・ログイン実装・API代（数百円/月程度）が必要 |
| C. スキル | Claude との会話で「これ記録して」と写真を送る | 作るのが一番楽 | グラフを毎日見る・数字を手早く入れる用途には不向き |

**→ 案Aで作る。** 使ってみて不満が出たら、同じ画面とデータ構造のまま案Bに移せるように作る。

使う機能（アーティファクトのランタイム機能）:

- `sample`（画像あり）… 食事写真を Claude に渡してメニュー・栄養素を推定
- `db` … 記録の保存（夫婦それぞれ自分の分だけ書ける／お互いの分は見られる）
- `user` … 開いているのが夫か妻かを自動判定
- `assets` … 食事写真の保存（任意。容量節約のため縮小して保存）

## 2. 画面構成

スマホ縦向き前提。下部タブで4画面。

```
[ 今日 ] [ 記録追加 ] [ グラフ ] [ 設定 ]
```

### 2.1 今日（ホーム）
- 上部: 日付（← → で前後の日へ）、夫／妻 の切替（自分の記録を表示、相手の分は閲覧のみ）
- サマリーカード: 摂取カロリー / 目標、P・F・C、体重、睡眠時間、運動時間
- タイムライン: 朝食・昼食・夕食・間食・飲み会 の各カード（写真サムネ＋品目＋kcal）
- 未入力アラート: 「体重がまだです」「昨夜の睡眠を入れてください」

### 2.2 記録追加（大きなボタン6つ）
1. 📷 **食事（写真）** … ①②
2. 🍺 **飲み会** … ④
3. ⚖️ **体重** … ③
4. 😴 **睡眠** … ⑥
5. 🏃 **運動** … ⑧
6. ✏️ **食事（手入力）** … 写真を撮り忘れたとき用

### 2.3 グラフ … ⑤⑦⑧
- 期間切替: 1週間 / 1か月 / 3か月
- 表示切替: 自分だけ / ふたり重ねて
- グラフ一覧は §5

### 2.4 設定
- 表示名、身長、目標体重、1日の目標カロリー
- 「日付の区切り時刻」（初期値 4:00。深夜1時の飲み会は前日扱い）
- CSV書き出し（バックアップ用）

## 3. 各機能の流れ

### ① ② 食事写真 → Claude が食事リスト作成
1. 「食事（写真）」→ カメラ起動（または写真フォルダから選択）
2. 食事区分を選ぶ（朝/昼/夕/間食。時刻から自動で初期選択）
3. 端末側で写真を長辺 1024px 程度に縮小 → Claude に送信
4. Claude が返す内容（JSON）:
   ```json
   {
     "items": [
       {"name": "白ごはん", "amount": "茶碗1杯(約150g)", "kcal": 234,
        "protein": 3.8, "fat": 0.5, "carbs": 55.7, "fiber": 0.5, "salt": 0.0}
     ],
     "total": {"kcal": 650, "protein": 25, "fat": 20, "carbs": 90, "fiber": 4, "salt": 3.2},
     "confidence": "medium",
     "note": "揚げ物の衣の量で ±100kcal 程度ぶれます"
   }
   ```
5. 確認画面で品目・量・数値を修正可能（「半分残した」→ 量×0.5 ボタン）
6. 保存。写真は縮小版を保存（設定でOFF可）

記録する栄養素: **カロリー、たんぱく質、脂質、炭水化物、食物繊維、塩分**（必要なら後で糖質・野菜量など追加）

### ③ 体重
- 数値入力（0.1kg単位）。前回値を初期表示し ＋/− で微調整
- 1日1回（同日に入れ直したら上書き）。任意で体脂肪率

### ④ 飲み会（写真なし）
入力項目:
- 「飲み会」ラベル＋メモ（店名など任意）
- **腹何分目**: 1〜10 のスライダー
- **お酒の量**: 種類ごとに杯数を ＋/− で入力

| お酒 | 1杯の基準 | 純アルコール | 概算kcal |
|---|---|---|---|
| ビール 中ジョッキ | 500ml | 20g | 200 |
| ハイボール | 350ml | 14g | 110 |
| チューハイ・サワー | 350ml | 14g | 180 |
| 日本酒 | 1合 180ml | 22g | 190 |
| ワイン | グラス 120ml | 12g | 90 |
| 焼酎（水・お湯割り） | 1杯（焼酎60ml相当） | 14g | 85 |

- 自動計算: **純アルコール量（g）**、お酒のカロリー
- 料理のカロリーは「腹何分目」から概算（例: 腹8分目 ≒ 1,000kcal を基準に比例）。画面上は「推定」と表示し、グラフでは飲み会の日に🍺マークを付ける

### ⑥ 睡眠（毎朝入力）
- 「寝た時刻」「起きた時刻」を時刻ピッカーで入力（前日の値を初期表示）
- 睡眠時間は自動計算（23:30 → 6:45 のように日付をまたいでもOK）
- 記録は **起きた日** に付く
- 任意: 睡眠の質 ☆1〜5

### ⑧ 運動
- 「朝の運動」「夜の運動」それぞれ **分数** を入力（0, 15, 30, 45, 60 のワンタップボタン＋自由入力）
- 任意で種類（ウォーキング / ランニング / 筋トレ / ヨガ / その他）

## 4. データ設計

ユーザーごとに `u/{ユーザーID}/...` の下に保存。**自分の分だけ書ける・ふたりとも両方読める** ルールにする。

```
u/{uid}                         プロフィール
  name, heightCm, goalWeightKg, goalKcal, dayStartHour(=4)

u/{uid}/meals/{mealId}          食事（写真・手入力・飲み会 共通）
  date: "2026-10-20"
  slot: "breakfast" | "lunch" | "dinner" | "snack" | "party"
  time: "12:15"
  photoId?: アセットID
  items: [{name, amount, kcal, protein, fat, carbs, fiber, salt}]
  total: {kcal, protein, fat, carbs, fiber, salt}
  source: "ai" | "manual" | "party"
  party?: {fullness: 1-10, drinks: {beer: 2, highball: 1, ...},
           alcoholG, drinkKcal, foodKcalEstimate, memo}

u/{uid}/days/{YYYY-MM-DD}       1日1ドキュメント
  weightKg?, bodyFatPct?
  sleep?: {bed: "23:30", wake: "06:45", minutes: 435, quality?: 1-5}
  exercise?: {morningMin, nightMin, morningType?, nightType?}
```

アクセスルール:
```js
db: { rules: [
  { path: "u",        read: "view", write: "owner" },
  { path: "u/{self}", write: "interact" }   // 自分の配下だけ書ける
]}
```

グラフ用の日別集計（摂取カロリー合計など）は表示時に計算する（データ量は2人×1日数件なので十分速い）。

## 5. グラフ（⑤⑦⑧）

| グラフ | 形 | 補足 |
|---|---|---|
| 体重の推移 | 折れ線＋7日移動平均線 | 目標体重を点線で表示 |
| 摂取カロリー | 積み上げ棒（P/F/C由来のkcal）＋目標線 | 飲み会の日は🍺マーク |
| 睡眠時間 | 棒グラフ（時間） | 下段に就寝・起床時刻の帯グラフ（寝る時刻のばらつきが見える） |
| 運動時間 | 積み上げ棒（朝／夜） | 週の合計分数も表示 |

- 「ふたり重ねて」モードでは夫・妻を色分けして同じ軸に表示
- グラフライブラリ: Chart.js（cdnjs から読み込み）
- ダークモード対応

## 7. 決めてほしいこと

1. **奥様の claude.ai アカウント** … お持ちですか？（案Aでは必要。無い場合は案Bを検討）
2. **お互いの記録を見られる設定でOK？** … 初期案は「書けるのは自分の分だけ、見るのはふたりとも」
3. **目標値** … 目標体重・1日の目標カロリーを入れるか（空欄でも動く）
4. **食事写真を保存するか** … 保存すると後で見返せる。しない場合は解析後に破棄
5. **日付の区切り** … 深夜の飲み会を前日扱いにする区切り（初期値 朝4時）でよいか
