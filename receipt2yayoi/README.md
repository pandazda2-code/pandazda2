# receipt2yayoi

レシートの写真を撮って放り込むと、**弥生会計にそのまま取り込める仕訳CSV**を作るツールです。
確定申告のレシート入力を手打ちから解放するのが目的です。

## できること

1. レシート写真を読み取る（日付・店名・金額・税率別内訳・インボイス登録番号）
2. 勘定科目と貸方（現金/未払金など）を自動で当てる
3. **台帳にためる**（撮るたびに1枚ずつ追加。同じ写真は二重計上しない）
4. 台帳まるごとから弥生の仕訳インポートCSVと、人間確認用CSVを作り直す

## 2つの使い方

### A. スマホから、その場で1枚ずつ（おすすめ）

Claude に「**確定申告の写真取り込み**」と言ってレシート写真を送るだけです。
`.claude/skills/receipt-import/` のスキルが動いて、読み取り→台帳に追加→CSV更新→
保存まで自動でやります。パソコンの操作もAPIキーも要りません。

> ✅ 4/5 スターバックス 渋谷店 1,100円 を「会議費」で登録しました。
> 今年はこれで 23枚・48,300円です。

### B. パソコンで、たまった写真をまとめて

```
$ receipt2yayoi add ~/Pictures/レシート2026 --year 2026
  読み取り中… IMG_0412.jpg
  ✓ 2026-03-01 JR東日本 東京駅 1,340円
  読み取り中… IMG_0413.jpg
  ✓ 2026-03-02 ファミリーマート 918円

2枚を追加（スキップ 0 / 失敗 0）。台帳は合計 23枚。

レシート 23枚 → 仕訳 31行 / 合計 48,300円
  弥生インポート用: out/yayoi_import_2026.csv
  確認用一覧      : out/review_2026.csv
  ⚠ 要確認 2行。review_2026.csv を直してから取り込んでください。
```

## 弥生への取り込み方

- **弥生会計（デスクトップ）**: メニューの「ファイル」→「インポート」で `out/yayoi_import_2026.csv` を指定
- **やよいの青色申告オンライン / スマート取引取込**: 「ファイル取込」から同じCSVを指定

どちらもファイル経由です。弥生には写真を直接投げる一般公開APIがないため、
壊れにくいこの経路を採っています。

## セットアップ

使い方Aだけなら不要です。使い方B（パソコンでまとめて処理）のときだけ:

```bash
pip install -e .
export ANTHROPIC_API_KEY=sk-ant-...   # または `ant auth login`
```

## コマンド

| コマンド | すること |
|---|---|
| `receipt2yayoi add <写真 or フォルダ>` | 写真を読み取って台帳に追加し、CSVを作り直す |
| `receipt2yayoi record --image <写真>` | 読み取り済みの内容をJSONで台帳に記録（チャット添付用） |
| `receipt2yayoi build` | 台帳からCSVだけ作り直す |
| `receipt2yayoi list` | 台帳の中身を一覧表示する |

共通オプション: `--year 2026`（その年の分だけCSVにする）、`-o out`（出力先）、
`--ledger ledger/receipts.json`（台帳の場所）

## 台帳のこと

読み取り結果は `ledger/receipts.json` にたまっていきます。CSVは毎回この台帳から
**まるごと作り直す**ので、「追記したつもりが前の分を消した」という事故が起きません。

台帳のキーは**画像の中身のハッシュ**です。同じ写真をファイル名を変えて送っても
二重計上になりませんし、読み取り済みの写真は二度とAPIに送らないので費用もかかりません。

勘定科目のルール（`rules.py`）を直したあとは `receipt2yayoi build` だけで
CSVが作り直せます。写真を読み直す必要はありません。

## 設計上の判断

- **勘定科目はまずルール表で決める**（`rules.py`）。確定申告は毎年同じ店が出てくるので
  ルールの的中率が高く、「去年と同じ科目になる」一貫性も保てます。
  当たらなかったものだけ `雑費` ＋ **要確認フラグ**にして人間に回します。
- **推測しない**。日付や金額が読めなければ空のまま要確認にします。
  勝手に埋めた数字が申告書に載るほうが怖いためです。
- **インボイス登録番号がないレシートは経過措置の税区分**（`課対仕入10%区分80`）を当てます。
- 要確認の行は弥生の**付箋1**が立つので、取り込んだ後も画面上で見分けられます。
- **台帳が正、CSVは使い捨て**。CSVを手で直しても次回上書きされます。恒久的な修正は
  ルール（`rules.py`）か台帳そのものに入れてください。

## 確認は必ず人間が

`review.csv` をExcelで開いて、特に「要確認」の行を見てから取り込んでください。
勘定科目の最終判断は事業者本人の責任です。金額の大きいもの、家事按分が要るもの
（家賃・通信費など）は必ず目視してください。
