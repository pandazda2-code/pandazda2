# receipt2yayoi

レシートの写真を撮って放り込むと、**弥生会計にそのまま取り込める仕訳CSV**を作るツールです。
確定申告のレシート入力を手打ちから解放するのが目的です。

## できること

1. スマホで撮ったレシート写真（フォルダごとまとめてOK）を読み取る
2. 日付・店名・金額・税率別内訳・インボイス登録番号を抽出
3. 勘定科目と貸方（現金/未払金など）を自動で当てる
4. 弥生の仕訳インポート形式CSV（Shift_JIS・25項目）と、人間確認用のCSVを出力

```
$ receipt2yayoi ~/Pictures/レシート2026 -o out
  読み取り中… IMG_0412.jpg
  読み取り中… IMG_0413.jpg

レシート 2枚 → 仕訳 3行 / 合計 2,258円
  弥生インポート用: out/yayoi_import.csv
  確認用一覧      : out/review.csv
  ⚠ 要確認 1行。review.csv を直してから取り込んでください。
```

## 弥生への取り込み方

- **弥生会計（デスクトップ）**: メニューの「ファイル」→「インポート」で `out/yayoi_import.csv` を指定
- **やよいの青色申告オンライン / スマート取引取込**: 「ファイル取込」から同じCSVを指定

どちらもファイル経由です。弥生には写真を直接投げる一般公開APIがないため、
壊れにくいこの経路を採っています。

## セットアップ

```bash
pip install -e .
export ANTHROPIC_API_KEY=sk-ant-...   # または `ant auth login`
```

## 使い方

```bash
receipt2yayoi <画像ファイル or フォルダ> [-o 出力先] [--dry-run] [--no-cache]
```

- `--dry-run` … APIを呼ばず、読み取り済みキャッシュだけでCSVを作り直す
- `--no-cache` … キャッシュを無視して読み取り直す

読み取り結果は出力先の `.receipt2yayoi-cache.json` に保存されます。
勘定科目のルールを直して作り直すときも、写真を読み直さないので費用がかかりません。

## 設計上の判断

- **勘定科目はまずルール表で決める**（`rules.py`）。確定申告は毎年同じ店が出てくるので
  ルールの的中率が高く、「去年と同じ科目になる」一貫性も保てます。
  当たらなかったものだけ `雑費` ＋ **要確認フラグ**にして人間に回します。
- **推測しない**。日付や金額が読めなければ空のまま要確認にします。
  勝手に埋めた数字が申告書に載るほうが怖いためです。
- **インボイス登録番号がないレシートは経過措置の税区分**（`課対仕入10%区分80`）を当てます。
- 要確認の行は弥生の**付箋1**が立つので、取り込んだ後も画面上で見分けられます。

## 確認は必ず人間が

`review.csv` をExcelで開いて、特に「要確認」の行を見てから取り込んでください。
勘定科目の最終判断は事業者本人の責任です。金額の大きいもの、家事按分が要るもの
（家賃・通信費など）は必ず目視してください。
