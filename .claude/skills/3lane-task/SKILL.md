# 3レーン・タスク

自分専用のタスク管理アプリ。claude.ai のアーティファクトとして公開済みで、サイドバーにピン留めしてある。

- URL: https://claude.ai/artifact/Hy3oaTHQvEmoBD8eoDQ12P
- タイトル: `3レーン・タスク`（変えない）
- 元のHTML: `assets/task-calendar.html`（このスキルに同梱）

## 機能

- **用途**（仕事・プライベートなど）を上のチップで切り替える。名前の変更・追加・削除は「用途を編集」から（タスクか履歴がある用途は削除不可）。
- 用途ごとに4タブ:
  - **48時間**: 追加から48時間の期限カウントダウン。終わったら完了→「完了を履歴へ移す」で入れ替え。
  - **今週**: 月〜日の日付マス。各タスクに「時間・量」を付ける。‹ › で週移動。
  - **今月**: 今月達成すること（目標量つき）。
  - **履歴**: 完了したタスクを月ごとに保存。直近12か月の完了数グラフと、月ごとの一覧。
- 毎週金曜 21:00 を過ぎると「週次更新」バナーが出て、全用途の完了分を履歴に移す。

## データ（アーティファクトの db、本人のみ読み書き: rules read/write = owner）

| パス | 中身 |
|---|---|
| `tasks/<id>` | `{text, lane: "h48"|"week"|"month", space, done, createdAt, doneAt, day?: "YYYY-MM-DD", amount?}` |
| `history/<YYYY-MM>` | `{month, items: [{text, lane, space, amount, day, doneAt}]}` 完了月ごとに追記 |
| `meta/spaces` | `{list: [{id, name}]}` 用途。初期値は `work`=仕事, `private`=プライベート |
| `meta/review` | `{lastAt}` 最後に週次更新した時刻(ms) |

`space` が無い古いタスク・履歴は先頭の用途に属するものとして扱う。

## 修正するとき

1. `Artifact` の `read` で上のURLを読み、返ってきた最新版を元に編集する（`assets/` のHTMLは控え。ずれていたら公開中の方が正）。
2. 同じURLを `url` に指定して publish する（新しいURLを作らない、`<title>` は `3レーン・タスク` のまま、`capabilities` は省略して既存の db ルールを引き継ぐ）。
3. データ構造を変えるときは既存データ（上の表）を壊さないこと。データの確認・修正は `ArtifactData` で行う。
4. 修正後は `assets/task-calendar.html` も最新版で上書きしておく。
